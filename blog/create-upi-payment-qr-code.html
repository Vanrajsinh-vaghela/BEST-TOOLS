NPCI Official UPI Deep Link URL Syntax

The National Payments Corporation of India (NPCI) specifies a standard URI schema for all UPI payment requests:

// Standard Static UPI Deep Link Syntax upi://pay?pa=shopkeeper@okicici&pn=GeneralStore&cu=INR // Optional Fixed Amount UPI URI Syntax upi://pay?pa=shopkeeper@okicici&pn=GeneralStore&am=250.00&cu=INR // Parameter Breakdown: // pa = Payee Virtual Address (UPI ID) // pn = Payee Name (Appears on Customer Screen) // am = Transaction Amount (Optional pre-filled bill value) // cu = Currency Code (INR)

NPCI Parameters Guide for UPI QR Codes

Parameter Key Meaning Example Value
pa Payee UPI VPA Address (Required) mobile@ybl / name@upi
pn Payee Name (Required) SuperMarketStore
am Pre-filled Amount (Optional) 150.00
cu Currency Code (Required) INR

Frequently Asked Questions (FAQs)

Will a static UPI QR code accept payments from any bank app?

Yes! NPCI standards mandate that any valid UPI QR code must accept payments from all UPI-enabled apps in India.

Are there transaction charges on static UPI QR transfers?

No, standard UPI bank-to-bank transfers via static QR codes are 100% free of transaction fees for small merchants and individuals.
