PAN Card Photograph Preparation Rules

  • Use a clear and recent photograph that follows the current application instructions.
  • Keep the face clearly visible and avoid excessive shadows or blur.
  • Crop unnecessary background while keeping the required framing.
  • Do not over-compress the photograph because excessive compression can make facial details unclear.
  • Check the final pixel dimensions, file format and KB size before uploading.

PAN Card Signature Preparation Rules

  • Sign clearly on clean paper according to the current application instructions.
  • Keep the signature readable and avoid excessive blank space around it.
  • Crop the image carefully without cutting any part of the signature.
  • Convert the file to the required image format if necessary.
  • Check the final file size and dimensions before submitting the application.

How to Compress PAN Photo Without Making It Blurry

1. Crop Before Compressing

Cropping unnecessary background reduces the amount of image data that needs to be compressed. This often gives better results than aggressively lowering JPEG quality.

2. Resize Only When Necessary

If your original smartphone image is extremely large, resizing it to the dimensions required by the application can significantly reduce the file size.

3. Reduce JPEG Quality Gradually

Do not immediately select the lowest quality setting. Reduce compression gradually and inspect the final image for blur, artifacts and readability.

4. Check the Final File

Before uploading, confirm that the file is within the required KB limit and uses the correct dimensions and format specified by the current application instructions.

Why Is My PAN Photo Upload Showing an Error?

  • The file size is outside the permitted range.
  • The image dimensions do not match the current requirement.
  • The uploaded format is not accepted.
  • The image is too blurry, dark or unclear.
  • Too much of the photograph was cropped.
  • The application portal has changed its current upload requirements.
